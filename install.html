Install Lintel

A faster board for SIT's room booking system, on your laptop or phone.

Lintel is an unofficial student project. It is not affiliated with or endorsed by SIT. You need your own SIT account. See the privacy policy.

Chrome

For laptops and desktops. It takes about a minute.

1. Add it from the Chrome Web Store

Open the store page and click Add to Chrome.

Open the Chrome Web Store

2. Confirm

Click Add extension.

Chrome says Lintel can “read and change your data” on rbs.singaporetech.edu.sg. That’s how it changes the page layout. It’s limited to that one site. See what Lintel does and doesn’t do.

3. Pin it (optional)

Click the puzzle piece at the top right of Chrome, then click the pin next to Lintel so it’s easy to find.

4. Open the booking site

Go to rbs.singaporetech.edu.sg and log in as usual. Lintel appears by itself.

iPhone

Lintel runs in Safari with the help of a free app called Userscripts.

1. Get the Userscripts app

Install it from the App Store. It’ll say Get if you don’t have it yet.

Open the App Store

2. Open the app once

Open Userscripts, then close it. You don’t need to change anything.

3. Find it in Settings

Open Settings, then Apps, Safari and Extensions. Tap Userscripts.

4. Turn it on

Turn on Allow Extension. Under website access, allow rbs.singaporetech.edu.sg and lintel.leeguanfeng.com.

5. Tell Safari to open it with Userscripts

You only do this once. Safari treats a .user.js file as a web page, so it shows the script as text until you say otherwise — that is Safari’s behaviour, not a broken download.

Tap aA (or the puzzle-piece icon) in the address bar, choose Manage Extensions, and make sure Userscripts is allowed on lintel.leeguanfeng.com. On iPad or Mac you can instead pick Always Allow on This Website.

6. Install Lintel

Tap the button, then tap the Userscripts icon in the address bar and confirm the install.

Install on iPhone

Seeing code instead of an install prompt? The extension is not allowed on this site yet — go back to step 5. The button deliberately opens the script so Userscripts can read it; there is no file to download.

7. Open the booking site

Go to rbs.singaporetech.edu.sg in Safari and log in as usual. Lintel appears by itself.

Using it

Search for a room, then tap free slots on the board. Swipe sideways to see later times.

Check your selection and tap Book this slot. Nothing is booked until you confirm.

Android

  1. Install Firefox.
  2. In Firefox, add the Tampermonkey extension.
  3. In Firefox, tap the button below and confirm the install.
  4. Open the booking site in Firefox and log in.
Install on Android

Updates install automatically. To stop using Lintel, remove it from Chrome, Userscripts or Tampermonkey.
