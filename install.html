Install Lintel

A faster board for SIT's room booking system, on your laptop or phone.

Lintel is an unofficial student project. It is not affiliated with or endorsed by SIT. You need your own SIT account. See the privacy policy.

Chromelaptop or desktop · 4 steps · about a minute⌄
1. Add it from the Chrome Web Store

Open the store page and click Add to Chrome.

Open the Chrome Web Store
2. Confirm

Click Add extension.

Chrome says Lintel can “read and change your data” on rbs.singaporetech.edu.sg. That’s how it changes the page layout. It’s limited to that one site. See what Lintel does and doesn’t do.

3. Pin it (optional)

Click the puzzle piece at the top right of Chrome, then the pin next to Lintel so it’s easy to find.

4. Open the booking site

Go to rbs.singaporetech.edu.sg and log in as usual. Lintel appears by itself.

iPhoneSafari + Userscripts · 7 steps⌄

Lintel runs in Safari, with the help of a free app called Userscripts. Every step below happens on your iPhone.

1. Get the Userscripts app

Install it from the App Store. It’ll say Get if you don’t have it yet.

Open the App Store
2. Note where Userscripts keeps scripts

Open the app once and look at Current Directory at the bottom. That is the folder Lintel has to sit in — you’ll come back to it in step 5.

Unless you changed it, it reads Userscripts App Documents, which is Files → On My iPhone → Userscripts. If you pointed the app at iCloud instead, it will read something like iCloud Drive/Userscripts — use whichever one the app shows you.

3. Turn the extension on

Open Settings, then Apps, Safari, Extensions, and tap Userscripts. Turn on Allow Extension, then allow it on rbs.singaporetech.edu.sg.

4. Download the script

Open this page in Safari, then tap the button. Safari saves the file straight to its Downloads folder — there’s no “where do you want to save this” prompt to answer.

Download for iPhone

If your iPhone shows the script as a page of text instead of saving it, press and hold the button and choose Download Linked File. Either way the file ends up in Downloads.

5. Move it into the Userscripts folder

Tap the downloads button in Safari’s toolbar (a circle with a down arrow), then Downloads. You’ll see lintel.user.js there.

Press and hold the file, choose Move, then go to the folder from step 2 — On My iPhone → Userscripts, or iCloud Drive → Userscripts — and tap Move.

6. Let Userscripts pick it up

Open the Userscripts app (or tap aA → Userscripts in Safari once). Lintel now appears in its list, and from then on it loads on the booking site by itself.

7. Open the booking site

Go to rbs.singaporetech.edu.sg in Safari and log in as usual. Lintel appears by itself.

You never repeat this. The file carries its own update address, so Userscripts checks it and lists new versions under Available Updates in the aA → Userscripts panel. Prefer not to touch the Files app? Install straight from that panel instead — both routes end in the same folder.

AndroidFirefox + Tampermonkey · 4 steps⌄
  1. Install Firefox.
  2. In Firefox, add the Tampermonkey extension.
  3. In Firefox, tap the button below and confirm the install.
  4. Open the booking site in Firefox and log in.
Install on Android
Using Lintelthe board, booking, and what is safe⌄

Search for a room, then tap free slots on the board. Swipe sideways to see later times.

Check your selection and tap Book this slot. Nothing is booked until you confirm.

Everything runs in your own browser session. Nothing is sent anywhere, and Lintel never books without your confirmation.

Updates install automatically. To stop using Lintel, remove it from Chrome, Userscripts or Tampermonkey.
