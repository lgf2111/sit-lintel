Install Lintel

A faster board for SIT's room booking system, on your laptop or phone.

Lintel is an unofficial student project. It is not affiliated with or endorsed by SIT. You need your own SIT account. See the privacy policy.

Chrome

For laptops and desktops. It takes about a minute.

1. Add it from the Chrome Web Store

Open the store page and click Add to Chrome.

Open the Chrome Web Store

2. Confirm

Click Add extension.

Chrome says Lintel can “read and change your data” on rbs.singaporetech.edu.sg. That’s how it changes the page layout. It’s limited to that one site. See what Lintel does and doesn’t do.

3. Pin it (optional)

Click the puzzle piece at the top right of Chrome, then click the pin next to Lintel so it’s easy to find.

4. Open the booking site

Go to rbs.singaporetech.edu.sg and log in as usual. Lintel appears by itself.

iPhone

Lintel runs in Safari, with the help of a free app called Userscripts. Chrome on iPhone cannot run Safari extensions, so it can only ever show you the script's text — use Safari for every step below.

1. Get the Userscripts app

Install it from the App Store. It’ll say Get if you don’t have it yet.

Open the App Store

2. Open the app once

Open Userscripts and leave it as it is. It sets up its own folder in iCloud Drive, which is where the script will live. You can see the path it picked under Current directory.

3. Turn the extension on

Open Settings, then Apps, Safari, Extensions, and tap Userscripts. Turn on Allow Extension, then allow it on lintel.leeguanfeng.com and rbs.singaporetech.edu.sg.

4. Open this page in Safari

Open lintel.leeguanfeng.com/install in Safari — not Chrome — and stay on that tab for the next two steps.

5. Tap Install, then aA

Tap the button below. Safari will show the script as text: that is normal, not a failed download. The install controls live in Safari’s toolbar, not on the page.

Install on iPhone

Now tap aA in the address bar and choose Userscripts. The panel lists Lintel with a JS tag — tap the blue button beside it to install.

6. If the panel shows nothing

That means the extension is not allowed on this page yet — go back to step 3 and allow it on lintel.leeguanfeng.com, then reload and tap aA again.

Prefer the Files app? Long-press the page and choose Download Linked File, then move lintel.user.js from Downloads into iCloud Drive → Userscripts. Same result — the file carries its own update address — but you must open the Userscripts panel once afterwards so it picks the file up.

7. Open the booking site

Go to rbs.singaporetech.edu.sg in Safari and log in as usual. Lintel appears by itself.

Keeping it up to date

You do not have to reinstall. The script names its own update address, and Userscripts checks it on its own; new versions show up under Available Updates in the same aA → Userscripts panel. Tap aA there whenever you want to check by hand.

Using it

Search for a room, then tap free slots on the board. Swipe sideways to see later times.

Check your selection and tap Book this slot. Nothing is booked until you confirm.

Android

  1. Install Firefox.
  2. In Firefox, add the Tampermonkey extension.
  3. In Firefox, tap the button below and confirm the install.
  4. Open the booking site in Firefox and log in.
Install on Android

Updates install automatically. To stop using Lintel, remove it from Chrome, Userscripts or Tampermonkey.
